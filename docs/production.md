### production

- all productions run on race's owned planet (s)
- production runs until it is canceled
- production requires planet's "effort"

### ship group build

creates ship group with state "orbiting" and planet with current race's tech levels
- reduces planet's materials

### ship group upgrade

updates ship group's tech levels up to selected levels
- reduces planet's materials

### tech research

updates race's selected tech level

### science research

updates > 1 tech levels at once

### materials production

updates planet's materials

requires planet's resources

### capital production

updates planet's industry and thus capital
- reduces planet's materials

### colonists production

updates planet's population and thus colonists. this is always runs as background production for population planets
